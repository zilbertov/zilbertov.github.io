Atlas Backups

Atlas Backups is a private utility for encrypted backups to an account owner's Google Drive. It is configured and operated by that owner; it is not a public file-sharing or AI service.

Backup contents are encrypted with Restic before upload. The app uses the drive.file permission to create, read, update and remove only Google Drive files used with this app. Backup retention is configured by the owner.

It does not request access to Gmail, Calendar, contacts or all existing Drive files. This informational website has no sign-in form, analytics or application credentials.
